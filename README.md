# FixItCity 🚧

FixItCity is an iOS app that allows users to report road hazards such as potholes, damaged signs, and other infrastructure issues.

## Features

* 📸 Capture photos of road hazards
* 📍 Automatically record the user's location
* 💾 Store reports locally using Core Data
* ☁️ Upload report images to AWS S3

## Tech Stack

* **Swift / SwiftUI**
* **Core Data**
* **Core Location**
* **AVFoundation**
* **AWS S3 / Amplify**
